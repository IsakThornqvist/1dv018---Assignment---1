## How to run the experiments

### 1. Clone the repository

```bash
git clone https://github.com/IsakThornqvist/1dv018---Assignment---1.git
```

### 2. Open the assignment folder

```bash
cd 1dv018---Assignment---1
```

### 3. Install matplotlib

The experiments use matplotlib to display the graphs.

```bash
pip install matplotlib
```

### 4. Run the experiments

```bash
python main.py
```

The `main.py` file automatically runs the experiments for Part 1 and Part 2 and displays the generated graphs.
